🚀 Featured projects
🌊 Blockchain-Based Blue Carbon MRV System
A transparent platform for registering, monitoring, verifying, and trading blue carbon credits from coastal ecosystems like mangroves and seagrass.
Solidity smart contracts (built and tested with Brownie) for minting tokenized credits, peer-to-peer trading, and automated benefit distribution to local communities
Django REST Framework backend linking on-chain data with off-chain storage, aligned with India's NCCR standards and Net Zero 2070 goals
Cut verification turnaround from months to hours by automating MRV workflows end to end
`Solidity` `Brownie` `Django REST` `ERC-20`
🤖 Policy-RAG-System
A RAG chatbot for Apmosys that gives website visitors accurate, policy-specific answers instantly.
End-to-end pipeline: document ingestion and chunking, embeddings for semantic retrieval, and LLM answers grounded in retrieved policy content
`Python` `LangChain` `RAG` `Embeddings`
🧑‍🔬 A New Distance Measure for Face Recognition
A face recognition approach built on the NUP (Normalized Unmatched Points) metric, aimed at long-distance, non-cooperative settings.
85.66%+ accuracy on benchmark datasets
Published in IJIRCCE (Vol. 11, Issue 4) and winner of Technothon 2023 National Hackathon
`Python` `Computer Vision` `OpenCV`
👓 Context-Aware Text Rendering via Webcam Distance Sensing
